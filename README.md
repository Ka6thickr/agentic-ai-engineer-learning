# Agentic AI Engineer Learning

12-week practical learning roadmap for Microsoft Agent Framework, Microsoft Foundry, Azure AI Search, MCP, GitHub Copilot Agent, and OpenAI Codex.

## Roadmap

1. Agent fundamentals
2. Tools and function calling
3. State, sessions and memory
4. RAG fundamentals
5. Agentic retrieval
6. MCP
7. Microsoft 365 and SharePoint integration
8. Workflows and multi-agent patterns
9. Microsoft Foundry Agent Service
10. Evaluation and observability
11. Security and enterprise architecture
12. Capstone hardening

## Weekly cadence

Saturday: learn the concept and build the smallest working version manually.

Sunday: delegate one bounded extension to GitHub Copilot Agent and Codex, then review and compare the results.

## Capstone

Build an Enterprise SharePoint Knowledge & Action Agent with permission-aware retrieval, controlled tools/actions, evaluation, observability, and security.

See `AGENTS.md` for coding-agent instructions and `resources/official-links.md` for official learning resources.
