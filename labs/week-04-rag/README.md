# Week 4 — RAG Fundamentals

## Objective
Build grounded question answering over a small document set.

## Saturday
- Create an Azure AI Search index or local development equivalent.
- Chunk and index a small set of documents.
- Return answers with source references.
- Add unsupported-question test cases.

## Sunday
Use Copilot Agent for ingestion automation and Codex for retrieval evaluation tests. Compare the results.

## Done when
The agent answers from the indexed content and returns useful source references.
