# Week 2 — Tools and Function Calling

## Objective
Learn how an agent calls typed functions and handles tool results.

## Saturday
- Add two or three typed tools to the Week 1 agent.
- Use simple mock tools such as document lookup or request-status lookup.
- Add input checks and error handling.
- Add tests for normal and error cases.

## Sunday
Give one new tool as a bounded task to GitHub Copilot Agent and Codex. Compare the code, tests, and documentation.

## Done when
The agent can call tools correctly and the main paths are covered by tests.
