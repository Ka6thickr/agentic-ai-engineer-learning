# Week 1 — Agent Fundamentals

## Objective
Understand the basic agent loop, instructions, model interaction, structured output, testing, and failure handling.

## Saturday lab
1. Read the Agent Framework overview and first-agent tutorial.
2. Create the smallest working .NET agent.
3. Add clear instructions and one structured response.
4. Add at least one automated test.
5. Record what you learned in `docs/learning-notes/week-01.md`.

## Sunday agent exercise
Create a bounded GitHub issue asking a coding agent to improve the project structure, add tests, and update the README without changing the intended behavior.

Run the task with GitHub Copilot Agent and Codex separately when possible. Compare the implementation, test coverage, explanations, and any changes you had to make manually.

## Completion criteria
- Working first agent
- At least one test
- README/run instructions
- Comparison notes for Copilot Agent and Codex
