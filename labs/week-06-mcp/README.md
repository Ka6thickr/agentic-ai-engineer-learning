# Week 6 — MCP

## Objective
Understand MCP tools and connect an agent to a small MCP server.

## Saturday
- Build or run a small MCP server.
- Expose one useful read-only capability.
- Connect the agent to the MCP tool.
- Add input checks and integration tests.

## Sunday
Ask Copilot Agent to add a second MCP capability and Codex to review the interface and test coverage.

## Done when
The agent can use the MCP capability and the integration is documented and tested.
