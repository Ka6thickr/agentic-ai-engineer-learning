# 12-Week Roadmap

## Week 1 — Agent fundamentals
Build a minimal .NET agent, add tests, and compare one improvement using Copilot Agent and Codex.

## Week 2 — Tools and function calling
Create typed tools and learn tool selection, validation, error handling, and testing.

## Week 3 — State, sessions and memory
Separate conversation history, session state, durable memory, and business data.

## Week 4 — RAG fundamentals
Build grounded document Q&A with retrieval and source references.

## Week 5 — Agentic retrieval
Compare classic RAG with Azure AI Search agentic retrieval using a small evaluation set.

## Week 6 — MCP
Expose one safe capability through MCP and connect it to the agent.

## Week 7 — Microsoft 365 and SharePoint
Add enterprise content discovery and permission-aware retrieval through clear integration interfaces.

## Week 8 — Workflows and multi-agent patterns
Build a deterministic multi-step workflow and introduce specialist agents only where they add value.

## Week 9 — Microsoft Foundry Agent Service
Move a suitable agent capability into a managed Foundry environment.

## Week 10 — Evaluation and observability
Measure correctness, grounding, tool selection, latency, and failure cases.

## Week 11 — Security and enterprise architecture
Review identity, authorization, data boundaries, prompt injection risks, and controlled actions.

## Week 12 — Capstone
Harden and demonstrate the Enterprise SharePoint Knowledge & Action Agent with architecture, tests, evaluation results, deployment notes, and a polished README.

## Weekly pattern

1. Learn the official material.
2. Build the smallest version manually.
3. Create a bounded engineering task.
4. Run the task with GitHub Copilot Agent and Codex where possible.
5. Review the code and tests yourself.
6. Record what you learned and what you changed manually.
